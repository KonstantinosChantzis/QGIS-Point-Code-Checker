about=Punktcode-Prüfer checks a point layer from a topographic survey (point number, code, line number, height) against a code list before the as-built plan is made: unknown codes, duplicate point numbers, lines with only one point and height outliers compared with the nearest points of the same code. Errors are listed in a table, shown as a coloured point layer and can be exported to GeoPackage, Excel or CSV. Optionally a line layer is created from the codes (points with the same code and line number are connected). Code list as CSV file (code;meaning;type) or as text. Interface in German and English. | Der Punktcode-Prüfer prüft einen Punktlayer aus einer Vermessung (Punktnummer, Code, Liniennummer, Höhe) gegen eine Codeliste: unbekannte Codes, doppelte Punktnummern, Linien mit nur einem Punkt und Höhenausreißer. Fehler als Tabelle und Fehlerlayer, Export nach GeoPackage, Excel oder CSV; optional Linienlayer aus den Codes.
